Get started

Get started

Artemis runs on Ubuntu 24.04 with the GNOME desktop. Setup is a few commands in a terminal.

Before you start

Artemis is in active development. The launcher starts the core, and the notch at the top of your screen connects to it. It uses a scripted agent or, with your Anthropic API key, Claude.

What you need

  • Ubuntu 24.04 (GNOME 46) and a microphone
  • Orca, the screen reader that comes with Ubuntu (turn it on with Super+Alt+S)
  • Git
  • Optional: an ElevenLabs API key, for the Morgan voice. Without one, the offline voice speaks.

Set up once

Get the code and run the setup script. It says what each step does before it does it, asks before installing anything except system packages, and never asks for an API key:

git clone https://github.com/BU-Hackathonz/Artemis.git
cd Artemis
bash infra/setup-ubuntu.sh

Install the notch, then log out and back in so GNOME finds it:

client/prototypes/water-desktop/install.sh

After you log back in, turn it on:

gnome-extensions enable artemis-water@bu-hackathonz.github.io

Start Artemis

From the repository folder, start the core with “Hey Artemis” on:

ARTEMIS_LISTEN_MODE=wake infra/start.sh

Push-to-talk (Ctrl+Shift+Space) works with or without the wake word. Leave out ARTEMIS_LISTEN_MODE=wake to use push-to-talk only.

It uses a scripted agent that always makes a Hello World program; the file and the run are real and still need your approval. Add --agent claude to use Claude. It asks for your Anthropic API key with a hidden prompt and never saves it.

For the Morgan voice, set ELEVENLABS_API_KEY in that terminal before you start. Keep the key to yourself: never paste it into a chat, an issue or a file in the repository.

On Windows

The Windows 11 build speaks through NVDA. Setup steps are in infra/README.md.
