Get started

Get started

Artemis runs on Windows 11. Setup is a few commands in a terminal.

Before you start

Artemis is in active development. Today you can try the voice tools and the desktop app's simulated demo. The one-step launcher that starts everything together is in review now.

What you need

  • Windows 11 and a microphone
  • NVDA, the free screen reader, recommended
  • Python 3.12 and uv
  • Git and Node.js
  • For the desktop app: Rust and the Microsoft C++ Build Tools

Set up voice

Get the code and install the core with its voice tools:

git clone https://github.com/BU-Hackathonz/Artemis.git
cd Artemis/server
uv sync --group voice --group dev --group security

Download the speech model and NVDA's connector once, before you need them:

uv run --group voice python -m artemis.voice.setup

Check your microphone. It asks you to speak for four seconds, then says what it heard:

uv run --group voice python -m artemis.voice.listen

Try the desktop app

From the client folder:

npm ci
npm run tauri dev

Choose Try in-memory demo to practise the approval flow with a simulated assistant. It creates no files and runs no code.
