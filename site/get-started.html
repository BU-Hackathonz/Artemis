Get started

Get started

Artemis runs on Windows 11. Setup is a few commands in a terminal.

Before you start

Artemis is in active development. The launcher starts the core and the desktop app together, with a scripted agent or, with your Anthropic API key, Claude.

What you need

  • Windows 11 and a microphone
  • NVDA, the free screen reader, recommended
  • Python 3.12 and uv
  • Git and Node.js
  • For the desktop app: Rust and the Microsoft C++ Build Tools

Set up voice

Get the code and install the core with its voice tools:

git clone https://github.com/BU-Hackathonz/Artemis.git
cd Artemis/server
uv sync --group voice --group dev --group security

Download the speech model and NVDA's connector once, before you need them:

uv run --group voice python -m artemis.voice.setup

Check your microphone. It asks you to speak for four seconds, then says what it heard:

uv run --group voice python -m artemis.voice.listen

Try the desktop app

Install the app's packages once, from the client folder:

npm ci

Then, from the repository folder, start the core and the desktop app together:

powershell -ExecutionPolicy Bypass -File infra\start.ps1

It uses a scripted agent that always makes a Hello World program; the file and the run are real and still need your approval. Add -Agent claude, with an Anthropic API key set in that window, to use Claude.

To practise the approval flow without the core, run npm run dev in client, open http://127.0.0.1:1420 in a browser and choose Try in-memory demo. It creates no files and runs no code.
