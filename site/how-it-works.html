How a request flows

From the moment you hold the shortcut to the moment you hear the result, every step is spoken, and nothing changes on disk without your keypress.

One request, start to finish

  1. You speak or typeHold Ctrl+Alt+Space from any app. Artemis stops talking, plays a short rising tone, then starts listening. Release the keys and it transcribes on your own computer.
  2. Artemis reads it back"Heard: create a Python program that prints Hello World." The text stays in an editable field, so a misheard word is easy to fix.
  3. The agent plans the workThe coding agent decides which files to create or edit. It can only ask for actions through a fixed set of tools. It has no shell and cannot install anything.
  4. You review the exact changeWrites pause for approval. Artemis speaks a summary built from the real edit, such as "1 file, main.py, 1 line", and the full diff is there to step through. Enter approves, Escape rejects.
  5. The code is scannedBefore a run, the code is checked for security problems. A serious finding blocks the run, and Artemis says what it found and where.
  6. You approve the runRuns need their own approval. The program starts with a fixed command, a time limit and none of Artemis's secrets.
  7. You hear the resultSuccess says what the program printed. Failure says the exit code and the first error line, word for word, then an explanation and a proposed fix.

The parts

Desktop app
A small Windows app with a request field, the approval dialog and a reviewable activity log. Every control works from the keyboard, and focus moves deliberately.
Core
A local service on your computer that keeps track of tasks, approvals and events. It only listens on your own machine and needs a secret token from the launcher.
Voice
Push-to-talk recording and speech recognition with Whisper, on your computer. Spoken output goes through NVDA when it runs, or the Windows voice when it doesn't.
Agent
Claude plans and explains changes. Everything it reads from your project is treated as data, never as instructions.
Safety gate
Checks every tool request, keeps paths inside your project, asks for approval and binds that approval to the exact change.
Runner
Writes approved files and runs programs with a fixed command, a timeout, an output limit and a minimal environment.
