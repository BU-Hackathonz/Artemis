How it works

How a request flows

From the moment you say “Hey Artemis” to the moment you hear the result, every step is spoken, and nothing changes on disk without your approval.

One request, start to finish

  1. Speak or type

    You say “Hey Artemis” and talk.

    Artemis hears its name, plays a short tone and the notch at the top of the screen shows it is listening. Say the request in the same breath or right after. Prefer keys? Hold Ctrl+Shift+Space from any app, talk, and release. Either way, speech is transcribed on your own computer.

  2. Read back

    Artemis says what it heard.

    "Heard: create a Python program that prints Hello World." The text also lands in the editable request field, so you can cancel, fix a misheard word and send it again.

  3. Plan

    The agent plans the work.

    The coding agent decides which files to create or edit. It can only ask for actions through a fixed set of tools. It has no delete tool, and a shell command, like a write or a run, waits for your approval.

  4. Review

    You review the exact change.

    Writes pause for approval. Artemis speaks a summary built from the real edit, such as "1 file, main.py, 1 line", and the full diff is there to step through. Enter approves, Escape rejects. With conversation mode on, you can say “approve” once it has been read to you.

  5. Scan

    The Python code is scanned.

    Python files are checked for security problems before each write or run (the launcher installs the scanner). A serious finding blocks it, and Artemis says what it found and where.

  6. Run

    You approve the run.

    Runs need their own approval. The program starts with a fixed command, a time limit and none of Artemis's secrets.

  7. Hear

    You hear the result.

    Success says what the program printed. Failure says the exit code and the final error line, word for word, then an explanation and a proposed fix.

The parts

Desktop
A small notch at the top of the GNOME desktop on Ubuntu. It shows when Artemis is listening, thinking or speaking, takes typed requests, and opens the approval dialog. Every control works from the keyboard, and focus moves deliberately. A Windows app does the same job on Windows.
Core
A local service on your computer that keeps track of tasks, approvals and events. It only listens on your own machine and needs a secret token from the launcher.
Voice
The “Hey Artemis” wake word and push-to-talk, with speech recognition by Whisper on your computer. Artemis speaks with an ElevenLabs voice you choose (Morgan by default). Without a connection or a key, an offline voice speaks instead. Orca keeps reading your screen.
Agent
Claude plans and explains changes. Everything it reads from your project is passed to it as untrusted data, not as instructions.
Safety gate
Checks every tool request, keeps paths inside your project, asks for approval and binds that approval to the exact edit or run you reviewed.
Runner
Writes approved files and runs programs with a fixed command, a timeout, an output limit and a minimal environment.
