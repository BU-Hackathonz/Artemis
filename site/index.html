artemis.

A development environment you run by voice, keyboard and screen reader. Built for blind developers, so no step needs sighted help.

Get started See how a request flows

What a first request sounds like

You say
Artemis, create a Python program that prints Hello World.
Artemis says
Heard: create a Python program that prints Hello World.
Artemis says
Create project hello-world with one file, main.py, 1 line. Press Enter to approve, Escape to reject.
You press
Enter
Artemis says
Run main.py with Python. No security findings. Enter to run.
You press
Enter
Artemis says
main.py ran successfully. It printed: Hello, World!

Every line is spoken in your own NVDA voice and kept in a log you can review, replay or read in braille.

Three promises

Speak or type
Hold Ctrl+Alt+Space and talk, or type the same request. Artemis reads back what it heard before anything starts, and you can correct it.
Approve every change
Nothing is written or run until you press Enter on the exact change. If the files change underneath, the approval is cancelled and asked again.
Hear the real result
Runs are real. Failures are spoken first, with the exit code and the first error line word for word, before any explanation.

Where Artemis is today

Artemis is being built at HackUMass 2026. Voice input and spoken output, the approval rules, the coding agent and the desktop app each work on their own. The core that joins them into one live run is in progress, so the desktop app's demo mode is simulated for now and says so.
