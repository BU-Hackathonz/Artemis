How it works

From your voice to a running program, in five clear steps.

  1. Speak

    You say "Hey Artemis" and talk.

    The notch lights up and Artemis listens. Or hold the shortcut instead. Either way it transcribes on your own computer.

  2. Confirm

    It reads back what it heard.

    "Heard: create a Python program…" The text also lands in the request field, so you can cancel, fix a misheard word and send it again.

  3. Review

    You hear the exact change.

    A summary built from the real edit, with the full diff to step through. Enter approves, Escape rejects.

  4. Scan and run

    It checks the code, then runs it.

    A security scan of any Python files first, then its own approval, a fixed command and a time limit.

  5. Hear

    You hear what really happened.

    What the program printed, or the exit code and final error line, then an explanation and a fix.

Everything you need to know

Which screen readers does it work with?

The demo runs on Ubuntu 24.04 with Orca. Artemis also has a Windows build that speaks through NVDA. Other screen readers aren't tested yet.

Does my voice leave my computer?

No. Speech is recognised locally with Whisper, held in memory only while you speak, and never saved or uploaded.

Is my code sent anywhere?

Your request, the open project's file names, the files the agent reads and its tool results (such as a program's output) go to Anthropic's Claude to plan changes. What Artemis says aloud goes to ElevenLabs to be voiced, with secrets removed first. Artemis sends nothing else. An approved program runs on your computer with your permissions.

Can it run anything it wants?

No. Every run needs your approval, Python files are scanned first, and it runs with a fixed command and a time limit. It's gated and limited, not an operating-system sandbox.

What if the shortcut doesn't work?

Another app may own it. Choose a different shortcut in Artemis, or use the Start listening button.

Ready to build without asking for help?

Artemis is in active development. The launcher runs the whole app with Claude or a scripted agent, and the browser-only in-memory demo uses a simulated assistant.
