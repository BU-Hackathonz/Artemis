What Artemis promises

Every change waits for you
Artemis speaks a summary built from the real edit, and the full diff is ready to step through. Enter approves. Escape rejects. A spoken "yes" never approves anything, and if the files change first, it asks again.
Your voice, not a second one
Speaks through NVDA when it runs, in your voice and speed, and sends the same line to your braille display.
Hear the real result
Runs are real. Failures say the exit code and the first error line, word for word, before any explanation.

What a first request sounds like

You say
Artemis, create a Python program that prints Hello World.
Artemis says
Heard: create a Python program that prints Hello World.
Artemis says
Create project hello-world with one file, main.py, 1 line. Press Enter to approve, Escape to reject.
You press
Enter
Artemis says
Run main.py with Python. No security findings. Enter to run.
You press
Enter
Artemis says
main.py ran successfully. It printed: Hello, World!

Every line is spoken and kept in a log you can review, replay or read in braille.

Where Artemis is today

Artemis is being built at HackUMass 2026. Voice input and spoken output, the approval rules, the coding agent and the desktop app each work on their own. The core that joins them into one live run is in progress, so the desktop app's demo mode is simulated for now and says so.
