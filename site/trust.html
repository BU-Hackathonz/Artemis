Accessibility and safety

Artemis is designed around a screen reader, and around one rule: the developer decides every change.

Built for screen readers

  • Your voice, not a second one. When NVDA is running, Artemis speaks through it, in your voice and at your speed, and sends the same text to your braille display. Without NVDA it uses the Windows voice. It never uses both at once.
  • Works from any app. Push-to-talk and spoken results work even when Artemis isn't the focused window.
  • Interruptible. Pressing push-to-talk stops current speech first, so Artemis never records itself. You can also stop or repeat the last line at any time.
  • Keyboard first. Approvals are Enter and Escape on a focused dialog. Focus moves to the dialog when it opens and back when it closes.
  • Nothing silent. Every pause, failure and completion is announced, and everything spoken is kept in a log you can review.

You approve every change

  • Exact approvals. An approval covers one exact edit or one exact run. If the files change before you decide, it is cancelled and asked again.
  • A spoken "yes" never approves. Approvals are keyboard-only, so a misheard word can't write or run anything.
  • Blocked actions stay blocked by default. When a security scan finds a serious problem, Enter alone rejects. Overriding takes a separate shortcut on the Approve button.
  • No shell, no installs. The agent can read files, propose edits and ask to run a program. That is the whole list.
  • Files are untrusted. Text in your project, such as a comment telling the AI to delete everything, is treated as data. No tool exists that could carry it out.

Your data

  • Speech stays on your computer. Recognition runs locally. Audio is held in memory only while you speak and is discarded after transcription. It is never saved or uploaded.
  • The agent uses Claude. Your request and the project files the agent reads are sent to Anthropic's Claude API to plan changes. The API key is never put in prompts, logs or speech.
  • Local only. The core listens on your own computer and requires a secret token for each launch, so websites can't control it.
  • This site has no cookies, analytics or scripts, and loads nothing from other servers.

Known limits

  • Programs run with approval, a static scan, a time limit and a minimal environment. That is gated and limited, but it is not an operating-system sandbox.
  • Artemis supports Windows 11 with NVDA. Other screen readers and systems are not tested yet.
  • Speech recognition can mishear names and symbols. Artemis reads every transcript back, and typing is always available.
