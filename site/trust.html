Accessibility and safety

Artemis is designed around a screen reader, and around one rule: the developer decides every change.

Built for screen readers

  • A voice of its own, beside Orca. Artemis speaks in an ElevenLabs voice you choose, while Orca keeps reading your screen. Without a connection or a key, the offline voice shares Orca's speech service, so Artemis stops only its own speech, never Orca's. One voice speaks each line, never two.
  • Works from any app. “Hey Artemis”, push-to-talk and spoken results work even when Artemis isn't the focused window.
  • Interruptible. Pressing push-to-talk stops current speech first, so what Artemis was saying isn't recorded. You can also stop or repeat the last line at any time.
  • Keyboard first. Approvals are Enter and Escape on a focused dialog. Focus moves to the dialog when it opens and back when it closes.
  • Nothing silent. Every pause, failure and completion is announced, and everything spoken is kept in a log you can review.

You approve every change

  • Exact approvals. An approval covers one exact edit, or for a run, the entry file you reviewed and its arguments. Other project files are not part of a run's approval. If the files for an edit change before you decide, it is cancelled and asked again.
  • A spoken "yes" never approves. Approvals are keyboard-only, so a misheard word can't write or run anything.
  • Blocked actions stay blocked by default. When a security scan finds a serious problem, focus starts on Reject and Enter alone can't approve. Overriding takes a separate shortcut on the Approve button.
  • No shell, no install tool. The agent's tools are: create or open a project, list and read files, propose new or edited files, run a Python file after approval, scan for security problems, and inspect a local HTML page.
  • Files are untrusted. Text in your project, such as a comment telling the AI to delete everything, is treated as data, not as an instruction. The agent has no delete tool, and any change it proposes still needs your approval. An approved program runs with your permissions, so read it before you approve.

Your data

  • Speech stays on your computer. Recognition runs locally. Audio is held in memory only while you speak and is discarded after transcription. It is never saved or uploaded.
  • The agent uses Claude. Your request, the project's file names, the files the agent reads and its tool results (such as a program's output) are sent to Anthropic's Claude API to plan changes. The API key is never put in prompts, logs or speech.
  • Spoken lines use ElevenLabs. The text Artemis says aloud is sent to ElevenLabs to be voiced, with secrets removed first. Your recorded voice is not. Without an ElevenLabs key, the offline voice speaks and nothing is sent.
  • Local only. The core listens on your own computer and requires a secret token for each launch, so websites can't control it.
  • This site has no cookies or analytics. Its one small script only runs the visual motion and the Pause motion button, and it loads nothing from other servers.

Known limits

  • Programs run with approval, a static scan, a time limit and a minimal environment. That is gated and limited, but it is not an operating-system sandbox.
  • Artemis is tested on Ubuntu 24.04 with Orca, and on Windows 11 with NVDA. Other screen readers and systems are not tested yet.
  • The wake word can miss a quiet voice or wake on a similar word. Push-to-talk always works, and nothing changes without your keypress.
  • Speech recognition can mishear names and symbols. Artemis reads every transcript back, and typing is always available.
